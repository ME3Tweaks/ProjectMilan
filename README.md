Project Milan is the porting pipeline for ME3Tweaks' port of the multiplayer component of Mass Effect 3 (2012) to Mass Effect 3 Legendary Edition (2021). This is a very large-scope project and requires significant resources to compile and setup.

## How to compile mod component
You will need:
 - Visual Studio 2026 with C# and C++ workloads
 - .NET 10 SDK
 - Java 21 or higher
 - JPEXs / FFDec
 - UDK 2015
 - ME3Tweaks Mod Manager 10.0 or higher (Debug build)
 - VANILLA Mass Effect 3
 - VANILLA Mass Effect 3 Legendary Edition (can have Milan installed but nothing else should be)
 - A lot of patience

Project Milan has multiple components including MilanHost, MilanServer, LEBinkProxy, ME3TweaksModManager, and others, that also are required for the resulting game to run.

This pipeline will build the barebones version of the mod.
